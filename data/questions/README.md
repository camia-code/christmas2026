# 題庫格式說明

把所有題目放在本資料夾的 `questions.json`，是一個 JSON 陣列。每輪遊戲會從中**隨機抽 10 題**（題庫不足 10 題時取全部）。

## 單一題目格式

```json
{
  "id": "q001",
  "question": "題目文字",
  "options": ["選項A", "選項B", "選項C", "選項D"],
  "answerIndex": 0,
  "explanation": "答案解析文字"
}
```

| 欄位 | 說明 |
| --- | --- |
| `id` | 題目唯一代號，建議 `q001`、`q002`… 不可重複 |
| `question` | 題目敘述 |
| `options` | 4 個選項的陣列（順序即顯示順序） |
| `answerIndex` | 正確答案在 `options` 中的索引，**從 0 開始**（0=第一個、3=第四個） |
| `explanation` | 答題紀錄頁與反饋時顯示的詳解 |

## 注意事項
- `options` 請固定放 4 個。
- `answerIndex` 範圍是 0～3。
- 目前檔內為 3 題範例（題目前綴「（範例題）」），正式題目請直接覆蓋或增補。
